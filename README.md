## Research and Publication

### Emotion Classification Using EEG Signals

I led a funded five-person research project investigating emotion and stress classification using EEG/EOG signals. The project included:

* CNN and LSTM model development
* EEG/EOG signal processing and feature extraction
* Evaluation using the DEAP dataset
* A low-cost BCI/IoT prototype
* Data-collection activities involving more than 30 volunteers

Our research achieved approximately **90% stress-classification accuracy** and was published in IEEE Xplore.

**Publication:**
[Optimizing Emotion Classification from EEG Signals: A Comparative Analysis of Optimization Techniques on the DEAP Dataset](https://ieeexplore.ieee.org/document/10498633)

The paper is published in **IEEE Xplore** and indexed in **Scopus**.
